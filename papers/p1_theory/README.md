## Title (working)
"Optimal Behavioral Priors for Bipartite Graph Ranking under Domain Heterogeneity: A Prior-Domain Match Theorem"

## Core theoretical claims
1. Prior-Domain Match Theorem: α*(β) = f(β) where β is domain behavioral mode
2. Anti-Loyalty Equivalence: anti-loyalty prior ≈ inverse-popularity with domain-dependent exponent
3. Rising-Stars Identifiability: conditions under which the metric recovers a causal estimand
